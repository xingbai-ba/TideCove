# TideCove × TideGleam

**一个只属于你自己的 AI 私聊。**

手机上一对一聊天，数据全在你电脑上，不经过任何第三方 IM。

当前版本：**1.2.38**

---

## 两个东西

| | 是什么 | 在哪 |
|---|---|---|
| **TideGleam** | 电脑端的服务端，接 AI、管会话、存数据 | `TideGleam.exe`（Windows，双击即用） |
| **TideCove** | 手机端的聊天窗口 | `TideCove.apk`（Android 7.0+） |

一句话：**TideGleam 是大脑，TideCove 是嘴和耳朵。**

---

## 下载

**仓库里就是完整包**，解压即用：

- `TideGleam\TideGleam.exe` —— 电脑端服务（约 90 MB，自带 Node 运行时，**不用装任何依赖**）
- `TideCove.apk` —— 手机端（48 KB）
- `启动.bat` —— 双击启动
- `使用说明.txt` —— 三步上手

Releases 里也放了一份打好包的 zip，懒得逐个下的可以直接拿。

---

## 三步就能用

1. 电脑上双击 **启动.bat**（或直接跑 `TideGleam.exe`）
2. 几秒后会自动弹出配对页面，上面有**服务器地址**和**配对码**
3. 手机装 `TideCove.apk`，填地址和配对码，连上

启动后会有一个黑色窗口，显示英文提示——**这个窗口不能关**，关掉就等于停止服务。窗口里还会报告两个可选工具（语音转文字 / 语音合成）是否启用，显示 `skipped` 就是没装，不影响聊天。

## 1.2.38 更新了什么

**语音输入**：点麦克风切到语音框 → 长按录音（有声纹）→ 松手自动转文字并发送。录音走 App 原生，绕开 WebView 采集不到麦克风的毛病。

**语音转文字**：本地 whisper-small，默认不带模型（900 多 MB），装法见下面「可选工具」。

**语音合成**：接 GPT-SoVITS，用你自己的音色；没配就退回系统声音（会明确告诉你）。

**日记**：先加载最新 3 条，往下翻再续；每条能编辑、删除；AI 写的显示你给它起的昵称。

**外观**：夜间（暗紫）/ 日间（纯白）切换，带渐变过渡，上下边框随模式变色。

**稳定性**：设置（含头像、背景图）同步到服务端，换域名自动恢复；语音工具挂掉会自动拉起；修了换头像/背景误发图的 bug。

## 1.2.5 带来的功能

**表情包**：自己上传（自动压缩），点一下就发；AI 会收藏你发的图，看气氛回发给你。

**主页**：点左上角头像进入，从左边滑进，占满全屏。头像、昵称、字体、主题、气泡色全收在这里。

**设置**：头像圆形裁剪 + 拖拽缩放，昵称、字体大小、聊天背景，一次性调完。

**主题配色**：换一次，按钮、图标、选中态、头部光晕全跟着变。头像、文字、对方气泡颜色保持不动，留着辨识度。

**日记**：你可以写，AI 也可以写——它写的会挂一个它自己昵称的标签（昵称在设置里改），一眼能分清。

**数据更稳**：设置和表情在服务端存一份副本，换域名、重装 App 后自动恢复。

## 关于 exe 未签名

`TideGleam.exe` **没有做代码签名**（个人项目，签名证书每年上千元，不值）。

第一次运行时 Windows 可能弹出「Windows 已保护你的电脑」，提示"未知发布者"——这是未签名软件的正常现象，不是病毒报警：

1. 点「**更多信息**」
2. 点「**仍要运行**」

想确认下载的文件没被改过，去 [Releases](../../releases) 里对照该版本说明中给出的 SHA256。

---

## 它不做什么

- **不经过任何第三方服务器**：消息从手机直接到你电脑
- **不收集数据**：聊天记录只在 `TideGleam\data\` 里
- **不联网初始化**：装完就能用，不需要注册账号
- **不依赖云端**：电脑关机就断，这是设计不是 bug

## 前提

电脑上要跑着 **DeepSeek Harness**（DSH）。TideGleam 会自动探测它的端口，探测不到就在 `config.json` 里手动指定：

```json
{ "dshUrl": "http://127.0.0.1:50052" }
```

## 可选工具（不装也能用）

启动脚本会自动检测，装了就启用，没装就跳过——**不影响聊天任何功能**。

### 一、语音转文字（让你说的话变成文字）

不装的话语音能发能回放，但 AI 收到的只有「[语音]」。

```bash
# 1. 装 Python 3.10/3.11（勾 Add to PATH）

# 2. 装依赖
pip install torch transformers librosa soundfile opencc-python-reimplemented av

# 3. 下模型（约 926 MB，走国内镜像）
set HF_ENDPOINT=https://hf-mirror.com
python -c "from huggingface_hub import snapshot_download; snapshot_download('openai/whisper-small', local_dir=r'D:\whisper-small')"

# 4. 把 whisper-small 文件夹放到 TideGleam\models\whisper-small\

# 5. config.json 里填 tools.python
```

首次转写约 10 秒（加载模型），之后每条 0.3~1 秒。

### 二、语音合成（让 AI 用你的音色说话）

需要自己部署 [GPT-SoVITS](https://github.com/RVC-Boss/GPT-SoVITS)，跑在 9880 端口。

```json
"tools": {
  "enabled": true,
  "python": "你的GPT-SoVITS\\venv\\Scripts\\python.exe",
  "ttsUrl": "http://127.0.0.1:9880",
  "ttsScript": "你的GPT-SoVITS\\app\\api_v2.py",
  "ttsArgs": ["-a", "127.0.0.1", "-p", "9880"],
  "refAudio": "参考音频路径.wav",
  "promptText": "参考音频里说的那句话"
}
```

配了 `ttsScript` 服务端会自动拉起（后台无窗口）。判据：合成的 wav 采样率 **32000 Hz** 才是 GPT-SoVITS，**22050 Hz** 是退回系统声音了。

## 已知限制

- 消息提示音在部分手机 WebView 上不响（系统 autoplay 策略）
- 同一时间只能连一台手机
- 本版不含长期记忆/数据库（上下文由 DSH 会话管理）
- 公网地址用 cloudflared 隧道时，每次重启都会变；换了地址要重新配对一次（设置会自动恢复）

## OneBot 接入（可选）

TideGleam 同时是一个 OneBot 11 服务端，外部机器人框架可以接进来：

```bash
# HTTP
curl -X POST http://127.0.0.1:8080/onebot/v11/send_private_msg \
  -d '{"message":"你好","user_id":10001}'

# WebSocket
ws://127.0.0.1:8080/onebot/v11/ws
```

只支持私聊；群、文件、好友关系链相关 action 会返回 `retcode 1404`。

## 关于源码

**本仓库只放交付物和文档，不放核心代码。**

服务端逻辑已编译进 `TideGleam.exe`（Node SEA + minify），前端页面随服务端分发。

唯一例外：`TideGleam\asr.py` 和 `asr_server.py` 是语音转写的工具脚本（可选功能），源码随包提供——方便你自己改模型路径或换别的识别模型。核心业务逻辑仍然只在 exe 里。

想改自己的版本，可以基于公开的接口文档自己实现。
