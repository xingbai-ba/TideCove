# TideCove × TideGleam

**一个只属于你自己的 AI 私聊。**
**一个界面，同时和多个 AI 聊天 —— Claude、Gemini、ChatGPT、Kimi、DeepSeek。**

手机上一对一聊天，数据全在你电脑上，不经过任何第三方 IM。

当前版本：**1.3.7**

---

## 两个东西

| | 是什么 | 在哪 |
|---|---|---|
| **TideGleam** | 电脑端的服务端，连 AI、管会话、存数据 | `TideGleam.exe`（Windows，双击即用） |
| **TideCove** | 手机端的聊天窗口 | `TideCove.apk`（Android 8.0+） |

一句话：**TideGleam 是大脑，TideCove 是嘴和耳朵。**

---

## 1.3.0 更新了什么

### 多 AI 对话（这一版的主角）

一个 App 里切换多个 AI，每个都是**独立对话**：历史分开、设置分开、互不干扰。

**不再需要 DSH（DeepSeek Harness）。** 启动时会自动扫描你电脑上装了哪些受支持的客户端/CLI，**有哪个连哪个，没有就跳过**：

| AI | 需要的命令 | 说明 |
|---|---|---|
| Claude Code | `claude` | **终端版本**（命令行工具，不是客户端） |
| Gemini CLI | `gemini` | **终端版本**（命令行工具，不是客户端） |
| Codex (ChatGPT) | `codex` | OpenAI Codex CLI |
| Kimi | `kimi` | Kimi Code CLI |
| DeepSeek Harness | 可选 | 装了就连，不装也不影响 |

> ⚠ **Claude Code 和 Gemini CLI 是终端版本**，没有桌面图标、不是 App。
> 安装、登录、使用都在「命令提示符 / PowerShell」里完成。别去找它们的客户端。


你只要在电脑上装好其中任意一个并登录，它就会出现在手机端的 AI 列表里。一个都没装也能启动，只是列表里没东西可聊。

### 每个 AI 独立设置

点右上角齿轮，改的是**当前这个 AI** 的：

- 头像（没设过就用它自己的图标）
- 昵称
- 气泡颜色
- 字体大小
- 聊天背景

切到别的 AI，外观跟着整套换。

### 公网访问改用 Tailscale

上一版用 Cloudflare 免费隧道，国内手机网络经常打不开（`网页无法打开`），所以换成了 **Tailscale**：点对点直连、地址固定、运营商拦不住。

代价是电脑和手机都要装一次，装完地址就永久固定了（`100.x.x.x`）。

### 其他

- 聊天图片可以点开大图后**保存到手机相册**（App 内直接写进 `Pictures/TideCove`）
- 修复了切换 AI 时历史串台的问题

## 上手总览（详细按键见 `使用说明.txt`）

1. **电脑**：装 `Tailscale-setup-1.104.7-amd64.msi` → 托盘右键 `Log in` → 浏览器登录
2. **电脑**：双击 `启动.bat`，记下窗口里的**配对码**，以及 Tailscale 控制台里电脑的 `100.x.x.x`
3. **手机**：装 `Tailscale-1.104.7.apk` → 用 **auth key** 登录（别点 Log in，见说明第 3.2 节）
4. **手机**：装 `TideCove.apk` → 地址填 `http://100.x.x.x:8080` → 填配对码 → 绑定
5. 顶部胶囊切换 AI，右上角齿轮改当前 AI 的设置

启动后的黑色窗口**不能关**，关掉就等于停止服务。

---

## 为什么要 Tailscale

手机在外网要访问你家电脑，需要一个地址。Cloudflare 的免费隧道域名在国内被大量拦截（表现为「网页无法打开」「ERR_FAILED」），所以改用 Tailscale：

- 地址固定：`100.x.x.x`，电脑重启也不变
- 点对点加密：不经第三方服务器中转你的聊天内容
- 不依赖域名，运营商拦不到

它只负责"让手机能连到电脑的 8080 端口"，不存任何数据。

---

## 不做什么

- **不需要注册账号**，没有云端服务
- **不上传聊天记录**，全部存在电脑的 `data\` 目录
- **不开放外网端口**，只通过 Tailscale 私有网络访问
- **不带模型**，AI 用你电脑上已经登录好的 CLI

---

## 前置要求

- Windows 10 / 11（x64）
- Android 8.0 以上
- 电脑上至少装一个受支持的 AI CLI 并完成登录（否则没有 AI 可聊）
- Tailscale 账号（免费版够用，GitHub / Google / 微软 / 邮箱都能登）

---

## 已知限制

- 切到 CLI 类 AI 时，回复要等 5~20 秒（每次起一个进程），且是整段返回、没有逐字流式
- CLI 类 AI 接不了图片，选它们时只发文字
- 语音输入需要本地 whisper 模型（可选，默认不带）
- 电脑端必须保持运行，黑色窗口不能关
