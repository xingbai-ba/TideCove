========================================
 TideCove 1.3.7  使用说明
========================================

【这一版最大的变化】

  · 不再需要 DSH（DeepSeek Harness）
  · 自动检测你电脑上装了哪些 AI，有哪个就连哪个
  · 每个 AI 独立对话、独立历史、独立设置
  · 一个界面，同时和多个 AI 聊天

【支持的 AI】（装一个用一个，没装就跳过）

  ⚠ 注意：Claude Code 和 Gemini CLI 是【终端版本】，不是桌面客户端！

    它们都是命令行工具，没有可以双击打开的图标，也不是 App。
    安装、登录、使用全部在「命令提示符 / PowerShell」里完成。
    想确认装没装：打开命令行，敲对应的命令看有没有反应。

    Claude Code       终端版本（命令行工具）
                      命令行敲 claude --version 有反应就算装好

    Gemini CLI        终端版本（命令行工具）
                      命令行敲 gemini --version

    Codex(ChatGPT)    命令行敲 codex --version

    Kimi Code CLI     命令行敲 kimi --version

    DeepSeek Harness  可选，装了就用，不装也不影响

  启动时程序会自己扫一遍，窗口里会列出结果：
    [OK] Claude
    [--] ChatGPT      <- 没装的就这样跳过

【为什么这一版要装 Tailscale】

  手机在外面要连家里的电脑，得有个固定地址。
  上一版用 Cloudflare 免费隧道，国内手机网络经常打不开（网页无法打开），
  所以 1.3.0 改用 Tailscale：点对点直连、地址固定、运营商拦不住。

  代价是电脑和手机都要装一次 Tailscale，装完就一劳永逸。


========================================
 第一步  电脑上装 Tailscale
========================================

 1.1  安装
   双击本文件夹里的：Tailscale-setup-1.104.7-amd64.msi
   → 点【Next】
   → 勾选【I accept...】
   → 点【Install】
   → 等进度条走完
   → 点【Finish】

 1.2  登录
   装完看屏幕右下角托盘区（时间旁边，可能要点向上的小箭头展开），
   会多出一个【黑白小方块】图标，那就是 Tailscale。
   → 右键这个图标
   → 点【Log in...】
   → 浏览器会自动打开登录页
   → 选【Sign in with GitHub】（有账号的话）
   → 或者选【Enter your email】用邮箱收验证链接
   → 登录完成后浏览器会提示成功，桌面托盘图标变成实心

 1.3  记下电脑的地址（等会儿手机要用）
   浏览器打开：
     https://login.tailscale.com/admin/machines
   → 列表里找到你这台电脑（名字可能是电脑名或 sacrifice）
   → 记下它旁边那个 100.x.x.x 的数字（例如 100.123.237.25）

 1.4  验证一下
   手机和电脑都装好 Tailscale 后，在电脑上打开浏览器，
   访问 http://你记下的那个100.x.x.x:8080
   能看到 TideCove 的登录页，说明通了。


========================================
 第二步  电脑上启动 TideCove
========================================

 2.1  双击【启动.bat】

 2.2  会弹出一个黑色窗口，里面会显示：

    [OK] claude            <- 检测到的 AI
    [--] codex            <- 没装，跳过
    配对码: 123456         <- 手机配对要用
    局域网: http://192.168.x.x:8080
    公网:   http://100.x.x.x:8080

 2.3  【重要】这个黑色窗口不能关！
   关掉窗口 = 停止服务，手机立刻就断了。

 2.4  第一次运行的安全提示
   TideGleam.exe 没做代码签名，Windows 会弹
   「Windows 已保护你的电脑 / 未知发布者」：
   → 点【更多信息】
   → 点【仍要运行】
   这是未签名程序的正常现象，不是病毒。


========================================
 第三步  手机上装 Tailscale
========================================

 3.1  把 Tailscale-1.104.7.apk 传到手机并安装
   （数据线、微信传文件、网盘都行）

 3.2  登录（重点：不要点 Log in）

   ⚠ 手机点 Log in 会跳浏览器打开 GitHub，国内经常打不开。
     所以我们用 auth key 登录，完全不碰浏览器。

   a) 回到电脑，浏览器打开：
        https://login.tailscale.com/admin/settings/keys

   b) 点页面上的【Generate auth key】
      → 弹出窗口里直接点【Generate key】
      → 复制生成的那串 tskey-auth-xxxxxxxx

   c) 打开手机上的 Tailscale App

   d) 点右上角的【设置】图标（齿轮 / 三条横线）

   e) 点【Accounts】

   f) 点这个页面右上角的【三个点】（kebab 菜单）

   g) 选【Use an auth key】

   h) 长按输入框，粘贴刚才复制的 tskey-auth-...

   i) 点确认

   j) 成功后：
      · 主界面顶部变成 Connected
      · 列表里会出现你电脑的 100.x.x.x 地址

 3.3  【重要】Tailscale App 要一直开着
   可以放后台，但别从最近任务里划掉，也别关。
   它一断，手机就连不上电脑。


========================================
 第四步  手机上装 TideCove 并配对
========================================

 4.1  安装 TideCove.apk

 4.2  打开 App，会要求【输入服务器地址】
   填：（把 x 换成第一步 1.3 记下的地址）
        http://100.x.x.x:8080

   ⚠ 注意是 http，不是 https
   ⚠ 地址里不要有空格

 4.3  输入配对码
   就是启动窗口里那个 6 位数字

 4.4  点【绑定】

 4.5  进去后先点右上角齿轮看版本
   显示「TideCove 1.3.7」就是新版本


========================================
 第五步  开始使用
========================================

 · 顶部右边有个紫色胶囊，显示当前 AI 名字（比如 DeepSeek）
 · 点它 → 弹出 AI 列表
 · 点你想聊的那个（绿点=可用，灰=没装/没登录）
 · 每个 AI 是独立对话，切来切去不会串

 · 点右上角齿轮 = 改【当前这个 AI】的设置
   可以单独改它的头像、昵称、气泡颜色、字体大小、聊天背景

 · 发图片后点开大图，底部有【保存图片】按钮
   App 里会直接存进手机相册（Pictures/TideCove）


========================================
 常见问题
========================================

 Q1: 手机提示「网页无法打开」
   ① 检查手机 Tailscale App 是不是开着、显示 Connected
   ② 检查地址是不是 http://100.x.x.x:8080（不是 https）
   ③ 检查电脑上那个黑色窗口还在不在

 Q2: 地址填对了还是连不上
   电脑上打开浏览器访问 http://100.x.x.x:8080 试试。
   电脑能开、手机不能开，说明 Tailscale 没连上（看 3.2 第 j 步）。

 Q3: 切换 AI 时看到别的 AI 的历史
   这通常是旧版本残留的缓存。
   → 手机设置 → 应用 → TideCove → 存储 → 清除数据
   → 重新配对一次（地址和配对码同上）
   1.3.0 已经修好这个问题。

 Q4: 某个 AI 点了提示「请登录」
   那个 AI 的命令行工具还没登录。在电脑的「命令提示符」里运行一次：
     claude   （Claude Code —— 终端版本，不是 App）
     gemini   （Gemini CLI —— 终端版本，不是 App）
     codex    （Codex）
     kimi     （Kimi）
   按提示走完登录，之后再点就能用了。

   ⚠ Claude Code 和 Gemini CLI 没有桌面图标，别去找 App。
     开始菜单搜「cmd」或「PowerShell」打开命令行，敲上面那些命令。

 Q5: 窗口里检测不到某个 AI
   说明它的命令不在 PATH 里。命令行敲一下验证：
     claude --version
     gemini --version
     codex --version
     kimi --version
   哪个没反应，就是没装或没配好。

 Q6: 手机老是要重新配对
   配对码是一次性的。如果电脑重启过、或者地址变过，
   需要重新看启动窗口里的新配对码。

 Q7: Tailscale 会不会偷看我东西
   它只是打一条加密的通道，让手机能访问你电脑上的
   TideCove（8080 端口），不经过任何第三方服务器存数据。
   所有聊天记录都在你自己电脑的 data 文件夹里。
