【启动窗口说明】

  启动后会弹出一个黑色窗口，上面是英文提示（比如 Starting server...）。
  这是正常的，英文是为了兼容各种 Windows 编码，不会乱码。

  窗口里会顺便告诉你两个可选工具的状态：
    · Speech-to-text: enabled / skipped     （语音转文字）
    · Text-to-speech: enabled / skipped     （语音合成）
  显示 skipped 就是没装，不影响聊天。

  【重要】这个窗口不能关，关掉就等于停止服务。


【第一次运行会弹安全提示】

  TideGleam.exe 没有做代码签名（个人项目，签名证书每年上千元，不值）。
  双击启动时 Windows 可能弹出「Windows 已保护你的电脑」，提示「未知发布者」——
  这是未签名软件的正常现象，不是病毒报警。

  点「更多信息」→ 点「仍要运行」，就正常启动了。

  想确认文件没被改过，去 Releases 页面看该版本说明里给出的 SHA256。


【1.2.35 更新了什么】

  语音
    · 点麦克风切到语音输入框，长按说话（有声纹），松手自动转文字并发送
    · 录音走 App 原生，绕开 WebView 采集不到麦克风的毛病
    · 语音条很细，显示秒数；长按语音条可「转文字 / 收起文字」

  日记
    · 只先加载最新 3 条，往下翻再续
    · 每条能编辑（铅笔）、删除（垃圾桶）
    · AI 写的日记显示你给它起的昵称

  外观
    · 夜间（暗紫）/ 日间（纯白）切换，带渐变过渡
    · 上下边框随模式变色（夜间浅紫、日间灰）
    · 主题配色全局生效，头像/文字/对方气泡保持不变

  稳定性
    · 设置（含头像、背景图）会同步到服务端，换域名后自动恢复
    · 语音工具挂掉会自动拉起，不用手动开
    · 修了换头像/换背景时图片误发到输入框的 bug
    · 顶栏状态固定「在线」，不再跳到「发送中 / 连接中」


【可选工具（不装也能用，装了更好）】

  下面两个都是可选的。启动脚本会自动检测：
    · 检测到 → 显示「已启用」，服务端会在后台拉起
    · 没检测到 → 显示「跳过」，不影响聊天任何功能

  ────────────────────────────────
  工具一：语音转文字（把你说的话变成文字）
  ────────────────────────────────

  作用：你发语音时，AI 才能听懂你说什么。不装的话语音能发能回放，
        但 AI 收到的只有「[语音]」两个字。

  一、装 Python 3.10 或 3.11
      https://www.python.org/downloads/
      安装时务必勾上「Add Python to PATH」

  二、装依赖（命令提示符里跑一次，慢就加清华源）
      pip install torch transformers librosa soundfile opencc-python-reimplemented av
      pip install ... -i https://pypi.tuna.tsinghua.edu.cn/simple

  三、下模型（约 926 MB，走国内镜像）
      set HF_ENDPOINT=https://hf-mirror.com
      python -c "from huggingface_hub import snapshot_download; snapshot_download('openai/whisper-small', local_dir=r'D:\whisper-small')"

      下完把 whisper-small 整个文件夹放到：
          TideGleam\models\whisper-small\

  四、配置
      把 TideGleam\config.example.json 复制成 TideGleam\config.json，
      改 tools 里的 python 路径：

          "python": "C:\\Python311\\python.exe"

  速度：服务刚起的第一条语音约 10 秒（加载模型），之后每条 0.3~1 秒。

  ────────────────────────────────
  工具二：语音合成（让 AI 用特定音色说话）
  ────────────────────────────────

  作用：AI 发语音时用你的音色，而不是系统那个机械女声。
        不装的话 AI 发的语音会是 Windows 自带的合成音。

  一、需要 GPT-SoVITS（一个独立的语音克隆项目，需自己部署）
      它自带 Python 环境和网页界面，跑起来后在 9880 端口提供服务。

  二、准备一段参考音频（5~10 秒，wav 格式），比如：
          E:\你的路径\参考音频.wav
      再准备好这段音频对应的一句话文字。

  三、配置 config.json：

          "tools": {
            "enabled": true,
            "python": "你的GPT-SoVITS\venv\Scripts\python.exe",
            "ttsUrl": "http://127.0.0.1:9880",
            "ttsScript": "你的GPT-SoVITS\app\api_v2.py",
            "ttsArgs": ["-a", "127.0.0.1", "-p", "9880"],
            "refAudio": "E:\你的路径\参考音频.wav",
            "promptText": "参考音频里说的那句话"
          }

  说明：配了 ttsScript 之后，服务端会自己把 GPT-SoVITS 拉起来（后台无窗口），
        你不用手动启动。没配就跳过，AI 语音退回系统声音。

  判据：合成出来的 wav 采样率是 32000 Hz 才是 GPT-SoVITS；
        22050 Hz 就是退回系统声音了。


【已知限制】

  · 消息提示音在部分手机 WebView 上不响（系统 autoplay 策略）
  · 同一时间只能连一台手机（设计如此，换设备要在管理页解绑）
  · 本版不含长期记忆/数据库（上下文由 DSH 会话管理）
  · 电脑关机或睡眠后手机连不上（服务器在你电脑上）
  · 公网地址每次重启隧道都会变，换了地址要重新配对一次
    （重新配对后，头像昵称表情背景都会自动恢复）
  · 语音转文字 / 语音合成默认关闭，要自己装（见上面「可选工具」）


【目录】

  启动.bat            双击这个启动（会自动检查可选工具）
  check-tools.ps1     启动时被调用，只做检测和提示，不装也不影响
  TideCove.apk        手机安装包（1.2.35）
  LICENSE             使用许可
  README.md           项目说明
  TideGleam\          服务端（不用动）
       TideGleam.exe
       public\
       asr.py              语音转文字脚本（可选）
       asr_server.py       转写常驻服务（服务端自动拉起）
       models\             放 whisper 模型（自己建，可选）
       config.example.json


【配置】（可选）

把 TideGleam\config.example.json 复制成 TideGleam\config.json 再改：

    port              端口，默认 8080
    dshUrl            DSH 地址，"auto" 自动探测
    replyTimeoutMs    回复超时，默认 90000
    onebot.reportUrl  事件上报地址（留空只走 WebSocket）
    tools.enabled     画图/语音/转写开关（默认 false）
    tools.python      语音相关工具用的 Python 路径
    tools.ttsScript   GPT-SoVITS 启动脚本（配了才会自动拉起）
    tools.asrModel    whisper 模型目录


【数据在哪】

TideGleam\data\ 下：
    device.json       已配对的手机（删掉 = 解绑）
    pair-code.txt     当前配对码
    history.jsonl     聊天记录
    diary.jsonl       日记
    settings.json     界面设置备份（头像/昵称/主题/背景）
    my-stickers.json  自上传的表情备份
    uploads\          图片、语音和合成文件
    session.json      AI 会话状态
    last-public-url.txt  上次的公网地址（变了会自动解绑）


【前提】

电脑上要跑着 DeepSeek Harness（DSH）。
本工具是 DSH 的附属品——没有它，服务端起得来，但聊不了天。
